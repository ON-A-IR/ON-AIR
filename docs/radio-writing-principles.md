# 청취자 중심 대본 생성

## 적용한 원리

- 도입에서 구체적인 생활 고민과 중심 궁금증을 세운다.
- 중간 전개는 고정 코너 순서 대신 앞 대화의 미해결 질문을 따른다.
- 질문자와 설명자 역할을 고정하지 않고 내용에 맞게 교대한다.
- 공감, 의심, 재해석, 다른 조건 제시로 대화에 새 의미를 더한다.
- 마지막에는 도입의 질문에 답하고 청취자가 가져갈 판단 기준을 남긴다.
- 실제 사연, 문자, 전화, 개인 경험을 만들어내지 않는다.
- 출처는 화면에서 표시하며 대사에서 게시글 제목이나 사이트를 소개하지 않는다.

## 분석 범위와 한계

첨부된 오디오의 자동 전사와 접근 가능한 방송사 공식 소개 자료에서
확인한 구성 원리를 프롬프트에 반영했다. 여러 SBS/MBC 방송 음성을
전체 청취하거나 모델 가중치를 재학습한 작업은 아니다.
특정 진행자의 대사나 말투를 복제하지 않는다.

규칙의 적용은 생성 결과의 품질을 보장하지 않는다.
실제 결과에서 반복, 사실 정확성, 중심 질문의 회수 여부를 확인해야 한다.
